# NextChat

👋 **NextChat** – это простой голосовой и текстовый чат, созданный на современном стеке для практики реального взаимодействия клиентов через WebSocket.

## 🚀 О проекте

NextChat позволяет пользователям общаться в реальном времени через **текст и голос**. В проекте реализованы:

- Подключение через socket.io  
- Голосовой чат  
- Интерфейс на React + Next.js с TailwindCSS и Material UI  
- Плавные анимации с framer-motion  
- Удобные слайдеры громкости с rc-slider

---

## 🛠️ Технологии

- **Frontend:** React, Next.js, TypeScript, TailwindCSS, Material UI, framer-motion, rc-slider  
- **Backend:** Node.js, socket.io

---

## ⚙️ Как запустить

```bash

# Запуск клиента
npm run dev

# Запуск сервера
npm run start:server

# Сборка проекта
npm run build

# Предпросмотр production-сборки
npm run preview

# Линтинг
npm run lint

```
